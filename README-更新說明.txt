DON’T LIKE YOUR MOM — v0.6.2 媽媽嘲諷顯示修復

這是更新包，不是完整遊戲。只需上傳以下四個檔案至 GitHub 儲存庫根目錄，覆蓋同名檔：

  1. index.html
  2. style.css
  3. script.js
  4. sw.js

問題原因：v0.5.7 雖然加入 16 種嘲諷台詞，但手機版 CSS 使用 .result-notice{display:none} 隱藏了台詞；好友挑戰還會覆寫這段文字。

修正：失敗結算頁，在標題下新增獨立的粉紅色媽媽嘲諷對話框。自由模式、舊式好友挑戰、雙人同步對戰都會顯示。每次右滑到媽媽，隨機挑選 16 種不同台詞，連續失敗不會抽到同一句。
成功結算不顯示對話框；原本的錯誤照片、媽媽標記、失敗原因、排行榜、99 張素材與 60 張預載程式均保留。

上傳後，完全關閉遊戲重新開啟，首頁頂部應顯示 v0.6.2。舊手機若仍看到 v0.6.1，請用瀏覽器直接重新載入並檢查 GitHub Pages 是否部署完成。

注意：本 ZIP 不含照片、不覆寫 leaderboard-config.js，不需要修改 Supabase SQL。
